## 本期视频内容

有朋友说想用 Claude Code，但用不明白命令行、不太习惯。这期就教大家用图形化的方式上手 Claude Code 桌面版，并配置第三方 inference 接口。

完整步骤：

 1️⃣ 官方地址下载并安装桌面版
 2️⃣ 在「帮助 → Troubleshooting」里开启开发者模式（Developer Mode）
 3️⃣ 在开发者模式里配置第三方 inference，选择 Gateway 形式、credential 选 static
 4️⃣ 在鱼鱼连线 yylx.io 中转站创建密钥（CC 分组），复制 Base URL 和 API Key 填入
 5️⃣ 测试模型，能拉到支持的模型列表就说明成功
 6️⃣ 在开发者菜单里打开 Chat，重启后 Chat / Cowork / Code 三个面板全部可用

配置完成后，你就能在一个软件里聊天、用 Cowork、写代码，完全不用碰命令行。

⚠️ 教程涉及的第三方接口配置请自行评估，按需使用。
